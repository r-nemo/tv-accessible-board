# テレビ型 デジタル意思伝達支援システム (TV Accessible Communication Board)

家庭用テレビ（REGZA等）と Fire TV Stick、標準テレビリモコン（十字キー・決定キー）を活用し、親指のわずかな動きのみで直感的に文章作成・高品質音声発話を行えるアクセシブルな意思伝達Webアプリケーションです。

---

## 主な機能と特徴

### 1. 2つの入力インターフェース
* **バージョン1 (`index.html` / `v1.html`) - 50音マトリクス文字盤**:
  * 画面全体に高コントラストな50音表、定型文、予測変換候補を配置。
  * リモコンの十字キーだけで滑らかに格子移動・入力・発話が可能。
  * Google CGI APIによる漢字変換サジェスト ＋ 過去履歴の自己学習サジェストを統合。
* **バージョン2 (`native_input.html`) - OSキーボード連携 ＋ 3×3履歴一覧**:
  * 決定ボタンでFire TV標準のオンスクリーンキーボード（またはAlexa音声認識）を直接呼び出し。
  * 下部に過去の履歴およびサジェストを3×3（9個）のカード形式で固定表示。
  * 枠線発光と確定的な2Dナビゲーションにより、画面外へのフォーカス喪失や描画切れを完全防止。

### 2. 臨床的・身体工学的な設計配慮
* **オーバースキャン防止セーフエリア**: テレビ画面端の切り落としを防ぐ余白設計（16:9比率最適化）。
* **超高コントラストUI**: 濃紺・黒背景に高輝度イエロー/エメラルドグリーンのフォーカス枠（常時視認性確保）。
* **スリープ防止（WakeLock）**: 長時間会話や待機時でもテレビ画面が消えないバックグラウンド制御。

### 3. 高品質肉声合成 ＆ サーバーレス構成
* **Google Cloud Text-to-Speech (Neural2)**:
  * 深層学習による極めて自然な人間の肉声（`ja-JP-Neural2-D`、落ち着いた男性声）。
  * 月間100万文字まで完全無料枠内で利用可能。
* **Cloudflare Workers 中継**:
  * APIキーをフロントエンドに露出させず、暗号化シークレットで安全に保管・中継。
  * 1日10万リクエストまで完全無料で運用可能。

## 利用方法

### GitHub Pages による常時ホスティング
GitHub Pages が有効化されているため、Fire TVのSilkブラウザから以下のURLで常時利用可能です：
* **バージョン1（50音表文字盤）**: `https://r-nemo.github.io/tv-accessible-board/`（または `/v1.html`）
* **バージョン2（キーボード連携版）**: `https://r-nemo.github.io/tv-accessible-board/v2.html`
